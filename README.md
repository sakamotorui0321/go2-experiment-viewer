# Go2 点群・RGB公開ビューアー

2026-10-16 静岡実験の3・4・6回目のRGB動画と累積点群の公開閲覧用サイトです。

[ブラウザーで開く](https://sakamotorui0321.github.io/go2-experiment-viewer/)

「RGB＋点群」で同時表示、「点群のみ」で点群単独表示に切り替えます。
共通時間バーで再生・停止・時刻移動できます。初回は測定ごとに数十MBの読み込みがあります。

保存時刻基準の対応付けで、撮影時刻の厳密な同期は未校正です。
点群は機体の推定位置・姿勢で補正した2cmボクセルの概略地図です。
検出枠は元のRGB映像に含まれます。記録のない区間は記録なしと表示します。

元の遠隔操作アプリと機器の操作・設定・認証情報は含めません。
Three.js 0.170.0: vendor/THREE-LICENSE.txt を参照してください。
